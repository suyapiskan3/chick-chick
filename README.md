# Чик-Чик — сайт парикмахерской

Одностраничный сайт парикмахерской «Чик-Чик» (г. Южно-Сахалинск, ул. Ленина, 182).

Весь код (HTML, Tailwind CSS через CDN, JavaScript) находится в одном файле `index.html`.

## Возможности

- Адаптивная вёрстка: шапка с контактами, главный блок, услуги с ценами, мастера.
- Онлайн-запись в 4 шага: услуги (сумма считается на лету), мастер, время, контакты.
- Уведомление об успешной записи.
- Демо-CRM в футере («Панель администратора»): таблица записей, хранение в `localStorage`, очистка базы.

## Запуск

Откройте `index.html` в браузере двойным кликом. Нужен интернет: Tailwind, иконки и шрифты загружаются с CDN.

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)`.

## Перед запуском в работу

- Замените номер телефона `+7 (4242) 55-55-55` на настоящий.
- Проверьте цифры в главном блоке (опыт, число гостей, рейтинг).
- Записи хранятся только в браузере посетителя; для реальной работы нужен сервер.
